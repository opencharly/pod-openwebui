The generator emits the box's stages but the stager materializes only the project's **own** candies: a
candy reached through a namespace import is resolved for its definition, not as build context. Every
existing consumer used an import as `base:` — a published-image **pull**, never a build — so this is the
first imported box anyone tried to build. `box generate` exits 0 and `box validate` is 0/0, so only the
build sees it. Filed as **`opencharly/charly#1294`** (blocking, claimed), with the error and the empty
staging directory as evidence.
