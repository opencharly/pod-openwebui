# 2026.326.1709 — feat(openwebui): wire ComfyUI image generation and editing

## Summary

Wire Open WebUI 0.13.4's ComfyUI image generation AND editing lanes:

- `env_accept` the full generation family (`COMFYUI_BASE_URL`,
  `ENABLE_IMAGE_GENERATION`, `IMAGE_GENERATION_ENGINE`, `IMAGE_SIZE`, `IMAGE_STEPS`,
  `COMFYUI_WORKFLOW`, `COMFYUI_WORKFLOW_B64`, `COMFYUI_WORKFLOW_NODES`) and the
  separate edit family (`IMAGES_EDIT_COMFYUI_BASE_URL`, `ENABLE_IMAGE_EDIT`,
  `IMAGE_EDIT_ENGINE`, `IMAGE_EDIT_MODEL`, `IMAGE_EDIT_SIZE`,
  `IMAGES_EDIT_COMFYUI_WORKFLOW`, `IMAGES_EDIT_COMFYUI_WORKFLOW_B64`,
  `IMAGES_EDIT_COMFYUI_WORKFLOW_NODES`).
- `secret_accept` `COMFYUI_API_KEY` and `IMAGES_EDIT_COMFYUI_API_KEY` at
  `charly/api-key/comfyui`.
- Entrypoint: decode the base64 workflow provides (env_provide rejects raw JSON
  braces), default the edit URL to the generation URL, derive `ENABLE_IMAGE_*` and
  the engines from resolved URLs, suppress the OpenAI edit connection inherited
  from `OPENAI_API_KEY`, and validate every workflow/node-map JSON before start.
- Docs: the three env lanes, the #28 inlined-constant workaround, and the edit-only
  `image`/`prompt` node map.

Workaround for opencharly/pod-openwebui#28 (owned by another slug): constants are
inlined in the workflow JSON; no fork or upstream patch.

## RCA

1. **Edit is a separate lane in 0.13.4.** `IMAGE_EDIT_ENGINE` defaults to `openai`
   and edit does not fall back to the generation URL. Fix: pin `comfyui`, default
   the edit URL, and derive the enable flag only when URL + workflow resolve.
2. **The OpenAI edit artifact.** `IMAGES_EDIT_OPENAI_API_KEY`/`BASE_URL` default to
   the chat provider, so a ComfyUI edit deployment could still synthesize a bogus
   OpenAI edit connection. Fix: the entrypoint empties both when the edit engine is
   `comfyui`; the live process shows both empty.
3. **Workflow transport.** `env_provide` expands Go templates and rejects raw JSON
   braces (caught by `charly box validate`). Fix: the provider ships base64, the
   entrypoint decodes it, and an operator's explicit JSON always wins.
